# Gantt Lab 📊

Mac 환경에서 실행 가능한 고성능 네이티브 Gantt Chart 일정 관리 데스크톱 애플리케이션입니다.  
Swift와 SwiftUI, AppKit을 기반으로 제작되어 최신 macOS에서 미려하고 부드러운 사용자 경험을 제공합니다.

---

## 🚀 실행 방법

### 방법 1. Finder에서 더블 클릭 (권장)
프로젝트 폴더 내 생성된 **`Gantt Lab.app`**을 Finder에서 더블 클릭하여 바로 실행할 수 있습니다.
터미널에서 열려면:
```bash
open "Gantt Lab.app"
```

### 방법 2. Swift 명령어로 직접 실행
```bash
swift run
```

### 방법 3. 릴리즈 앱 번들 재생성
```bash
./create_app_bundle.sh
```

## 🌟 주요 기능 안내

### 1. 메뉴 (Menu)
- **파일 (File)**
  - `새 프로젝트` (⌘N): 저장되지 않은 변경 내용이 있을 경우 저장 여부 확인 후 초기화.
  - `기존 프로젝트 읽기...` (⌘O): 저장된 프로젝트 파일(`.ganttlab` / JSON) 불러오기.
  - `저장하기` (⌘S): 현재 파일로 저장 (미저장 상태인 경우 Save As 대화상자 표시).
  - `다른이름으로 저장...` (⇧⌘S): 새 파일 이름과 경로를 지정하여 저장.
- **도움 (Help)**
  - `이 프로그램은...` (⌘?): 프로그램 정보, 버전, 핵심 기능 소개 팝업 창.

---

### 2. 좌측 화면 (Tree 형태의 작업 목록)
- **트리 폴딩**: 계층형 하위 작업 구조 및 접기/펼치기(Chevron) 지원.
- **인라인 편집**: 빈칸 또는 작업 이름을 클릭하여 즉시 이름 수정.
- **Shift-Enter 연속 입력**: 작업 이름 수정 중 `Shift + Enter`를 누르면 현재 작업을 저장하고, 동일한 레벨(동일 부모)의 다음 작업을 자동으로 생성한 뒤 곧바로 입력 상태로 전환.
- **작업 순서 이동 (위 / 아래)**:
  - **`⌘ + ↑` (위쪽 커서키)**: 선택된 작업을 트리 구조 상에서 한 칸 위로 이동.
  - **`⌘ + ↓` (아래쪽 커서키)**: 선택된 작업을 트리 구조 상에서 한 칸 아래로 이동.
- **트리 레벨 이동 (들여쓰기 / 내어쓰기)**:
  - **`⌘ + →` (오른쪽 커서키)**: 선택된 작업을 바로 위 형제 작업의 하위 레벨로 들여쓰기 (Indent). 작업에 하위 작업이 있다면 하위 작업들도 트리 구조를 유지하며 함께 이동.
  - **`⌘ + ←` (왼쪽 커서키)**: 선택된 작업을 부모 레벨로 내어쓰기 (Outdent). 하위 작업들도 함께 이동.
  - 툴바 및 마우스 우클릭 컨텍스트 메뉴에서도 즉시 레벨 이동 가능.
- **작업자 자동 합산 및 선택 규칙**:
  - **하위 작업이 없는 작업**: 작업자 칸 더블클릭 시 작업자를 직접 선택/배정 가능.
  - **하위 작업이 있는 작업**: 작업자 직접 선택이 제한되며, **하위 작업들에 참여 중인 모든 작업자들을 중복 없이(Distinct Union) 자동으로 합산**하여 표시.
- **기본 생성 규칙**: 새 작업 생성 시 미완료 상태, 시작일은 오늘, 종료일은 +7일로 기본 설정되며, 색상은 바로 위 작업의 색상을 자동으로 계승.
- **더블클릭 세부입력**: 작업 이름을 더블클릭하면 4단 구성의 "세부입력" 창 오픈.
- **완료 상태**: 완료 체크박스를 누르면 작업 이름이 회색(취소선)으로 변하고, 차트 Bar도 반투명하게 변경.
- **작업 색상 연동**: 작업 이름 앞의 색상 도트와 Gantt Chart 속 Bar 색상이 동일하게 유지.

---

### 3. 우측 화면 (Gantt Chart 타임라인)
- **Bar 자동 렌더링**: 작업의 시작일~종료일에 맞춰 부여된 색상으로 Bar 표시.
- **스마트 텍스트 배치**: Bar 너비가 작업 이름보다 길면 Bar 내부에 표시, Bar가 짧으면 Bar 오른쪽에 표시.
- **인터랙티브 드래그 & 리사이징**:
  - **왼쪽 끝 드래그**: 작업 시작일 조정 (종료일 고정).
  - **오른쪽 끝 드래그**: 작업 종료일 조정 (시작일 고정).
  - **가운데 드래그**: 기간을 유지하면서 Bar 전체를 좌우로 이동.
- **선후행 의존성 연결 (Shift-Click 화살표)**:
  - Bar 1개를 클릭하고, 다른 Bar를 `Shift` 키를 누른 채 클릭하면 두 Bar 사이에 화살표(Dependency) 연결 (이미 연결된 경우 토글하여 제거).
  - 종료일이 앞선 작업이 시작점이 되며, 앞선 작업의 Bar 끝에서 다음 작업의 Bar 시작점으로 베지어 곡선 화살표 연결.
  - **자동 일정 밀림 연동**: 앞선 작업의 종료일이 다음 작업의 시작일보다 늦을 경우, 다음 작업의 시작점을 `앞선 작업 종료일 + 1일`로 이동하고 기존 작업 기간(duration)에 맞춰 종료일도 자동 재계산.

---

### 4. 하단 화면 (작업자별 워크로드)
- 모든 작업자가 **가나다 순**으로 자동 정렬되어 표시.
- Gantt Chart의 날짜 열과 동일한 X축 상에서 일별 참여 작업 수를 1자리 숫자로 표시.
- **참여 작업 수 색상 규칙**:
  - `1~2개`: **연두색 (Lime Green)**
  - `3~4개`: **파란색 (Blue)**
  - `5개 이상`: **빨간색 (Red)**

---

### 5. 작업자 관리 창 (Assignee Manager)
- 아바타 이미지와 이름이 리스트 형태로 표시되며 다중 선택(체크박스) 지원.
- 우측 `+`, `-` 버튼으로 작업자 추가/삭제.
- 작업자 아바타를 **더블클릭**하면 사진 파일 선택기가 열리며, 선택된 이미지는 **무조건 32x32 크기로 리사이징**되어 적용.
- 하단 `확인`을 누르면 선택된 작업자가 해당 작업에 배정되고, `취소`를 누르면 기존 배정 상태 유지.

---

### 6. 세부입력 창 (Task Detail Inspector)
- **이동 가능한 플로팅 윈도우**: 창 배경이나 타이틀 바를 마우스로 잡고 화면 어디로든 자유롭게 이동 가능하며 크기 조절도 지원합니다.
- **창 1단**: 작업 이름 수정 + 우측 테마 색상 아이콘 (클릭 시 색상 팔레트 표시, 선택 시 **하위 계층 작업까지 일괄 색상 변경**).
- **창 2단**: 작업 기간:
  - **리프 작업**: 시작 날짜 - 끝 날짜 텍스트필드 직접 수정 및 DatePicker 캘린더 선택 지원 (종료일은 항상 시작일보다 미래 유지).
  - **하위 작업이 있는 부모 작업**: 기간이 **모든 하위 작업의 첫 시작부터 가장 늦은 종료 시점으로 자동 결정**되므로 수동 조작이 안전하게 비활성화됩니다.
- **창 3단**:
  - 기간 축소/연장 `+`, `-` 버튼: 1일 단위로 마감일 증감 실시간 반영. **하위 작업의 날짜는 건드리지 않고 연결된 의존성 후속 작업(Dependencies)의 일정만 지능적으로 연동**.
  - `완료하기` 버튼: 작업 완료/미완료 토글 (하위 작업들이 모두 완료되면 상위 작업도 자동으로 완료 표시).
- **창 4단**: 상세 설명 입력 (Markup / Markdown 텍스트 입력 및 실시간 렌더링 미리보기 탭 지원).
